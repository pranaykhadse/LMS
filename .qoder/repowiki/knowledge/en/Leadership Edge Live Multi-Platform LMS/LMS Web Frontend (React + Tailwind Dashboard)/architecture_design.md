Single-page React app bootstrapped from `src/main.tsx`, which mounts the root `<App />` component into `#root`. The application is organized in three layers: (1) `src/app/App.tsx` is a monolithic page component that drives multiple views via local state flags (`showViewAll`, `showCourseProgress`, `showRequiredCourses`, `showMentorModal`) rather than a router; (2) `src/app/components/ui/` provides a shadcn/ui-style primitive library built on Radix UI (`@radix-ui/react-slot`) and class-variance-authority for variant-driven components like Button, Dialog, Table, etc., with shared styling utilities in `utils.ts`; (3) `src/imports/` holds Figma-exported static assets and their auto-generated React wrappers (e.g. `CardDesign/index.tsx`) used as image placeholders. Styling is layered through `src/styles/index.css` which imports `fonts.css`, `tailwind.css`, and `theme.css`, while `web/` contains the PWA shell (`index.html`, `manifest.json`, icons). There is no client-side routing or data layer — all content is hardcoded mock data inside `App.tsx`.
