Standard Flutter Android project layout under `android/`. The root `settings.gradle.kts` pulls in the Flutter SDK's gradle tools from `local.properties`, applies the `dev.flutter.flutter-plugin-loader` and registers Kotlin/AGP versions, then includes only the `:app` module. The `build.gradle.kts` at the project root centralizes repositories (`google()`, `mavenCentral()`), redirects all build outputs to `../../build` so generated artifacts live alongside the Dart source tree, and wires subproject evaluation order. The `app/` module is an `com.android.application` with namespace `live.leadershipedge.app`, compiled with Java/Kotlin 11, and delegates compile/target SDK, NDK, version code/name to Flutter's `flutter.*` properties. `MainActivity.kt` extends `io.flutter.embedding.android.FlutterActivity` with no custom logic, making it a pure host. `AndroidManifest.xml` declares the launcher activity with `singleTop` launch mode, applies `LaunchTheme`/`NormalTheme`, sets `flutterEmbedding=2`, and adds the required `<queries>` block for text processing plugins. Resources under `res/` provide vector drawables for the splash screen and mipmap launcher icons across density buckets; `GeneratedPluginRegistrant.java` is auto-generated by the Flutter tooling to wire platform plugins into the Flutter engine at startup.
