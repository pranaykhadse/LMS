Standard Flutter iOS runner layout under `ios/`. The `Runner/` target is the Xcode app bundle whose entry point is `AppDelegate.swift`, a `@main` class extending `FlutterAppDelegate` and implementing `FlutterImplicitEngineDelegate` to register plugins via `GeneratedPluginRegistrant.register(with:)` during implicit engine initialization. App metadata, scene configuration (`UIWindowScene` with `FlutterSceneDelegate`), launch storyboard (`LaunchScreen.storyboard`), and main storyboard (`Main.storyboard`) live in `Runner/Info.plist` and `Base.lproj/`. Assets (app icons, launch images) are bundled via `Assets.xcassets`. Build configuration is split across `Flutter/Debug.xcconfig`, `Flutter/Release.xcconfig`, and `Flutter/Generated.xcconfig` (generated by Flutter). CocoaPods integration is declared in `Podfile`, which pins `platform :ios, '13.0'`, disables CocoaPods analytics, and delegates pod setup to Flutter's `podhelper` (`flutter_ios_podfile_setup`, `flutter_install_all_ios_pods`). A separate `RunnerTests` target inherits search paths for unit tests. Dependency direction: Runner depends on Flutter framework and any third-party pods; nothing inside this module depends on Dart code directly.
