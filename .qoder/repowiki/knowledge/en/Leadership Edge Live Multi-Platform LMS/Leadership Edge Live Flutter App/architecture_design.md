The module is a standard Flutter project split into three cooperating scopes: `lib/` holds the cross-platform Dart code (entry in `main.dart`, app bootstrap in `app_module.dart`, and feature modules under `app/` and `gen/`), while `android/` and `ios/` are thin native host shells that each launch the same Flutter engine and register plugins through auto-generated `GeneratedPluginRegistrant` files. The two platform shells share no Dart logic — they only declare metadata, permissions, and launch assets, so cross-child coordination happens entirely at the Flutter toolchain level rather than through shared code.
