Organized as a standard Flutter `test/` directory: `widget_test.dart` is the entry point for UI-level smoke tests that pump `MyApp` from `lib/main.dart`, while `payment/` groups feature-scoped unit tests. The payment subdirectory mirrors the source layout under `app/features/payment/`, testing the `PurchaseRecord` model's JSON round-trip (`toJson`/`fromJson`), `copyWith` immutability, list serialization helpers (`listToRawJson`/`listFromRawJson`), and `toString`. Two placeholder files (`iap_repository_test.dart`, `iap_viewmodel_test.dart`) are kept as stubs after IAP removal, preserving the feature folder structure.
