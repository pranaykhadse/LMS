The root `pubspec.yaml` declares the single Flutter package (`lms`) whose Dart source tree is consumed by three runtime targets: the `flutter_app` module (Android/iOS shells), the `desktop_platforms` module (Linux/Windows/macOS runners), and the `tests` module (unit/widget tests). A sibling `web_frontend` directory holds an independent React + Tailwind dashboard that shares business logic with the Flutter app only through the backend API contract rather than via code import. Cross-cutting concerns are centralized at this level: `analysis_options.yaml` enforces linting across all Dart code, `flutter_launcher_icons.yaml` drives icon generation for every platform target, `devtools_options.yaml` configures Flutter DevTools, and `dev_cors_proxy.js` plus `run_chrome_dev.bat` provide local development tooling used by both the Flutter and web frontends during debugging.
